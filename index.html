01 / Ethical Hacking

What is ethical hacking?

Authorized security testing that helps owners find and fix weaknesses before criminals exploit them.

Learn the workflow

Practice legally

04 / Cyber Security

Protect your accounts

Use unique passwords, a password manager, multi-factor authentication and account recovery options you control.

Avoid phishing

Check sender addresses and website domains. Do not open unexpected attachments or share one-time codes.

Keep devices safe

Install updates, use trusted app stores, review app permissions and enable device screen locks.

07 / Device Security Center

Windows laptop checklist

  • Turn on Windows Security / Microsoft Defender.
  • Install Windows and browser updates.
  • Use a standard account for daily work.
  • Review startup apps and installed programs.
  • Keep important files backed up.

Android phone checklist

  • Keep Android and apps updated.
  • Keep Google Play Protect enabled.
  • Remove apps you do not trust or use.
  • Review permissions and accessibility access.
  • Use a strong screen lock and 2-step verification.
